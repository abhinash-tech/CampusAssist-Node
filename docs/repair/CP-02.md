## 2. Action Required from User

To proceed with live cloud deployment to Render and Vercel, please confirm approval or perform the following steps:

### Step 1: Initialize Git and Push to GitHub
Run in the project root:
```powershell
git init
git add .
git commit -m "feat: CampusAssist production readiness with Aiven MySQL and Gemini AI"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPOSITORY_NAME>.git
git push -u origin main
```

### Step 2: Deploy Backend to Render
1. Log in to your [Render Dashboard](https://dashboard.render.com).
2. Click **New +** -> **Blueprint**.
3. Select the GitHub repository. Render will automatically read `render.yaml`.
4. Provide the environment variable values when prompted (Aiven MySQL host, user, password, port, and `GEMINI_API_KEY`).
5. Click **Apply**. Once deployed, copy your backend URL (e.g., `https://campusassist-api.onrender.com`).

### Step 3: Deploy Frontend to Vercel
1. Log in to your [Vercel Dashboard](https://vercel.com).
2. Click **Add New...** -> **Project** and import your GitHub repository.
3. Keep the Root Directory as `./` (Vercel will detect `vercel.json`).
4. In **Environment Variables**, add:
   - `VITE_API_BASE_URL`: `https://<YOUR_RENDER_BACKEND_URL>/api`
5. Click **Deploy**.
