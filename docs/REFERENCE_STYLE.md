# Visual reference notes

Reference site: https://hitit.com/

The reference homepage's observed content rhythm includes a large lead headline and proof points, an introductory innovation section, a solutions showcase, global-impact metrics, innovation strengths, and a structured footer. CampusAssist maps that rhythm to student support and campus services. It uses its own name, sample data and service copy rather than Hitit's trademarks or aviation product copy.

The current implementation is a high-level visual adaptation of the reference's editorial corporate style, not a pixel-for-pixel copy. For closer visual matching, compare the running page to a reference screenshot at the same viewport and iterate on exact spacing, typography and image crop.
