# CampusAssist project variants

- **Project 1 — CampusAssist-Node:** React/Vite + Node.js/TypeScript/Hono + Supabase PostgreSQL + Gemini API. This folder contains the Java-free variant.
- **Project 2 — CampusAssist-Java:** to be built separately later with React/Vite + Java Spring Boot + SQL database + Gemini API.

Keep separate repositories or at minimum separate root folders and deployment projects so the stacks, dependencies, and documentation do not become mixed.
